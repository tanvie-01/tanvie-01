### 🌱 Featured project: [Rooftop Garden](https://github.com/tanvie-01/rooftop-garden)

A Bangla-first web app that uses **NASA POWER** climate data and a live forecast to tell city families in Bangladesh what to grow on their roof, when to water, and how to save a sick plant. Built for the **NASA Space Apps Challenge 2026**.
